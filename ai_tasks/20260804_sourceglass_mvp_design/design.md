# Sourceglass ビジュアルデザイン仕様

**このデザインは装飾ではなく仕様である。** `✓` と緑を封じた時点で、状態を伝える主要な手段を
自ら捨てているため、代わりの体系がプロダクトの正しさを担保している。CodeX は勝手に崩さないこと。

視覚的な参照実装（実際に動く HTML）:
<https://claude.ai/code/artifact/afe097e6-a8b6-4093-8ef7-82626ca527fa>

---

## 1. 原則

1. **色相で判断を誘導しない。** 完全モノクロ。強調は**地と図の反転**で表現する
2. **差を伝えるチャンネルを絞る。** 混同すると実害が出るのは
   `NO_AI_RELATED_PROVENANCE_FOUND` と `NO_PROVENANCE_INFORMATION` の2つだけ。
   **そこにだけ差を集中させ、他は徹底的に均質にする**
3. **サマリは読み物、詳細は計測器。** 折りたたみを開く操作が、そのまま
   「一般向け → 専門向け」の切り替えになる
4. **外部リソースをゼロにする。** Web フォントも画像も読み込まない

---

## 2. カラートークン

中立色は純グレーではなく、**ごくわずかに寒色へ寄せたもの**を使う（レンズ・計測器の質感）。
単体では差が分からないが、画面全体では「選ばれた色」として効く。

```css
:root {
  --page:        #F4F5F7;
  --bg:          #FCFCFD;
  --fg:          #14161A;
  --muted:       #5C6370;
  --rule:        #E3E5EA;
  --rule-strong: #C6CAD2;
}
@media (prefers-color-scheme: dark) {
  :root {
    --page:        #0D0F12;
    --bg:          #15181C;
    --fg:          #E4E7EB;   /* 純白にしない。反転ブロックが眩しくなるため */
    --muted:       #969CA8;
    --rule:        #262A30;
    --rule-strong: #3B414B;
  }
}
```

**`--fg` を純白（`#FFF`）にしないこと。** 反転が「強調」ではなく「攻撃」になる。

---

## 3. 強調 = 地と図の反転

反転を**絶対的な色ではなく、地と図の関係として定義する。**
こうすることでライト・ダークどちらでも自動的に成立し、モード別の分岐が不要になる。

```css
.result--emph-head .result__head {
  background: var(--fg);
  color: var(--bg);
}
```

### 適用範囲: **A = 見出し行のみ反転（確定）**

ブロック全体を反転する案（B）は却下。

> 黒い塊は「エラー」「危険」の語彙である。**AI 生成は危険ではない。**
> ブロック全体を反転すると意味が過剰になる。A なら「ここは読め」で止まる。

**A の既知の弱点:** 詳細を開いてスクロールすると帯が視界から外れる。
実装後に問題が出るようなら、サマリー側にも同じ帯を出して対処する（今は入れない）。

## 4. 状態ごとのスタイル

| verdict / basis | 枠線 | 強調 | アイコン |
| --- | --- | --- | --- |
| `AI_RELATED_PROVENANCE` / explicit | 実線 | **見出し行を反転** | `i-warn` |
| `AI_RELATED_PROVENANCE` / heuristic | 実線 | なし | `i-warn` |
| `NO_AI_RELATED_PROVENANCE_FOUND` | **実線** | なし | `i-none` |
| `NO_PROVENANCE_INFORMATION` | **破線** | なし | `i-info` |

**実線と破線の差が、この4つの中で唯一の構造的な区別。**
「記録が無い」状態だけ枠を欠けさせることで、記号と文言に加えて**形でも**差がつく。

ドロップゾーンの枠も**破線**にする。「まだ何も入っていない」は「記録が欠けている」と
同じ意味なので、装飾ではなく同じ語彙として揃える。

## 5. タイポグラフィ

### Web フォントは使わない

読み込んだ瞬間に外部リクエストが発生し、CSP でも弾かれ、
「画像は出ないが利用した事実は漏れる」状態になる。**システムフォントのみで組む。**
制約ではなく、README に書ける事実である。

```css
--sans: system-ui, -apple-system, "Segoe UI", "Hiragino Kaku Gothic ProN",
        "Noto Sans JP", "Yu Gothic UI", Meiryo, sans-serif;
--mono: ui-monospace, SFMono-Regular, "SF Mono", Menlo, Consolas,
        "DejaVu Sans Mono", monospace;
```

### 等幅は英数字にだけ使う

**日本語を等幅ブロックに入れない。** ほぼ必ずフォールバックしてガタつく。

幸い、計測器パートに出るのはフィールド名と値なので構造上そもそも英数字しか来ない。
**詳細テーブルに和訳ラベルを置かない**（ラベルの和訳は読み物パート側に置く）。

### スケール

| 用途 | サイズ / ウェイト |
| --- | --- |
| ワードマーク | 1.0625rem / 640 / `letter-spacing: -.025em` |
| 結果の見出し | 1rem / 620 / `text-wrap: balance` |
| 本文 | 15px / 400 / `line-height: 1.75` |
| 注記・免責 | .875rem / `--muted` |
| データ（等幅） | .75rem / `font-variant-numeric: tabular-nums` |
| マイクロラベル | .625〜.6875rem / 等幅 / `letter-spacing: .1em` / 大文字 |

## 6. アイコン

**自前の極小 SVG を使う。** `⚠` などのテキスト記号は環境によってカラー絵文字として
描画され、モノクロ画面に突然オレンジが乗る。これはこの設計では致命傷になる。

`currentColor` で描くことで、反転にもダークモードにも自動追従する。

必要なのは3つだけ（`<symbol>` で定義して `<use>` する）。

| id | 用途 |
| --- | --- |
| `i-warn` | 三角＋感嘆符。AI 関連が見つかった |
| `i-info` | 円＋i。来歴情報が無い |
| `i-none` | 横線1本。AI 関連が見つからなかった |

実装は参照実装 HTML の `<defs>` をそのまま使う。

---

## 7. レイアウト

- 単一カラム。読み物パートは **62〜68ch** を上限に
- 角丸はほぼ使わない（2〜4px）。計測器としての性格を保つ
- 兄弟要素の間隔は `flex` / `grid` + `gap` で取る。個別 `margin` を使わない
- **詳細テーブルは `overflow-x: auto` を自前のコンテナに持たせる。**
  ページ本体が横スクロールしてはいけない
- サマリーの空欄は**空白にせず `—` で埋める**（空白は「調べていない」に見える）

---

## 8. やってはいけないこと

| 禁止 | 理由 |
| --- | --- |
| `✓` と緑を結果表示に使う | 「安全のお墨付き」と誤読される |
| 色相で状態を区別する | このデザインの前提が崩れる |
| Web フォントの読み込み | 外部リクエスト = プライバシー要件違反 |
| テキスト記号（`⚠` 等）をそのまま使う | カラー絵文字化してモノクロが破綻する |
| `--fg` を純白にする | ダークで反転が眩しくなり、強調が攻撃になる |
| 日本語を等幅ブロックに入れる | フォールバックでガタつく |
| 免責文言を折りたたむ | 仕様違反（`copy.md`） |
| ブロック全体を反転する | 「エラー・危険」に読まれる。AI 生成は危険ではない |
